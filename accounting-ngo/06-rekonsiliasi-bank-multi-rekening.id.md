# 06. Rekonsiliasi Bank Multi Rekening

> Prasyarat: [`01`](./01-jurnal-hibah-dan-fund-accounting.id.md) posted — saldo buku AST-01 = 83.000.000, AST-02 = 135.000.000 per 31 Januari 2026. Endpoint: `finance/bank-reconciliations/{create,update,complete}` (controller `Finance\BankReconciliations`). Field nyata: `bank_account_id`, `period_start`, `period_end` (`after_or_equal:period_start`), `opening_balance`, `closing_balance` (saldo buku sistem), `statement_balance` (saldo mutasi bank aktual), `notes`.
>
> **Koreksi penting dari draf lama**: sistem **TIDAK punya model baris rekonsiliasi/adjustment terpisah** (tidak ada `ReconciliationItem`/`ReconciliationAdjustment` di codebase) — rekonsiliasi di sini adalah **1 header per rekening per periode**, bukan daftar item yang dicentang satu-satu. `complete()` HANYA membandingkan `statement_balance` vs `closing_balance`; kalau `difference != 0`, request **ditolak/diblokir** (tidak completed) — sistem **TIDAK** membuat jurnal penyesuaian otomatis apapun. Kalau ada selisih (biaya admin, dsb), jurnal penyesuaian harus dibuat MANUAL lewat **Journals — `create`** lebih dulu supaya `closing_balance` (saldo buku) berubah, baru rekonsiliasi bisa `complete`.
>
> **🐛 Bug backend (sama seperti temuan di suite `accounting-ecommerce`)**: baris `BankReconciliations.php` yang menolak `complete()` saat `difference != 0` memanggil `response()->json()->warn([...])` — macro `warn()` **TIDAK terdaftar** di manapun di codebase (`grep -r "macro('warn'" app/` kosong). Panggilan ke method yang tidak ada akan melempar `BadMethodCallException` → response **500 Internal Server Error**, BUKAN 422/400 yang informatif. Test §2 di bawah harus memverifikasi ini sebagai bug nyata, bukan mengasumsikan "ditolak dengan pesan rapi".

## 1. Rekonsiliasi Bank Mandiri Umum (AST-01) — Matched Langsung

| Skenario              | Payload kunci                                                                                                                                                                                                                                | Hasil                                                                                                                             |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Positif — buat header | `POST finance/bank-reconciliations/create {bank_account_id:<AST-01>, period_start:"2026-01-01", period_end:"2026-01-31", opening_balance:50000000, closing_balance:83000000, statement_balance:83000000, notes:"Rekonsiliasi Januari 2026"}` | 201 — `reconciliation_number` auto-generate format `RCN/2026/01/0001`, `difference = 83.000.000 − 83.000.000 = 0`, status `draft` |
| Positif — complete    | `POST finance/bank-reconciliations/complete {slug}`                                                                                                                                                                                          | 200 — `difference = 0` → boleh completed                                                                                          |

## 2. Rekonsiliasi Bank BCA Donor Pendidikan (AST-02) — Ada Selisih Biaya Admin

Mutasi bank aktual menunjukkan saldo Rp 134.950.000 (bukan 135.000.000) — selisih Rp 50.000 biaya administrasi bank bulanan yang belum tercatat di sistem.

| Skenario                                                         | Payload kunci                                                                                                                                                                                                                                                     | Hasil                                                                                                                                                                                                                                                          |
| ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Positif — buat header                                            | `POST finance/bank-reconciliations/create {bank_account_id:<AST-02>, period_start:"2026-01-01", period_end:"2026-01-31", opening_balance:100000000, closing_balance:135000000, statement_balance:134950000, notes:"Rekonsiliasi Januari 2026 - ada biaya admin"}` | 201 — `difference = 134.950.000 − 135.000.000 = -50.000`, status `draft`                                                                                                                                                                                       |
| Negatif — complete dengan selisih belum nol                      | `POST finance/bank-reconciliations/complete {slug}`                                                                                                                                                                                                               | **Bug**: 500 Internal Server Error (`BadMethodCallException: Call to undefined method ... warn()`), BUKAN 422 rapi — TIDAK ada jurnal penyesuaian otomatis dibuat sama sekali (berbeda dari klaim draf lama yang bilang "jurnal penyesuaian terbuat otomatis") |
| Positif — buat jurnal penyesuaian manual dulu                    | `POST accounting/journals/create {date:"2026-01-31", lines:[{BBN-03, debit:50000, business_unit_id:<PRG-GEN>},{AST-02, credit:50000, business_unit_id:<PRG-GEN>}]}` → post                                                                                        | 201 — saldo buku AST-02 turun jadi **134.950.000**, sesuai mutasi bank aktual                                                                                                                                                                                  |
| Positif — update header rekonsiliasi dengan closing_balance baru | `PUT finance/bank-reconciliations/update {slug, closing_balance:134950000}`                                                                                                                                                                                       | 200 — `difference` recompute jadi `134.950.000 − 134.950.000 = 0`                                                                                                                                                                                              |
| Positif — complete                                               | `POST finance/bank-reconciliations/complete {slug}`                                                                                                                                                                                                               | 200 — sekarang selisih nol, completed                                                                                                                                                                                                                          |
