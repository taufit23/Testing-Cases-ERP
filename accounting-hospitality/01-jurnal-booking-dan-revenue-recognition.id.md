# 01. Jurnal Booking & Revenue Recognition

> Prasyarat: [`00-profil-perusahaan-dan-master-data.id.md`](./00-profil-perusahaan-dan-master-data.id.md) sudah lengkap (Modal Pemilik = 452.000.000, Trial Balance balanced, `USD` + 2 exchange rate ter-upsert). Semua transaksi bertanggal **Februari 2026** (periode Accounting Period Februari harus `is_closed:false`). Endpoint: `POST accounting/journals/create`, field validasi aktual: `code` (required, unique per branch), `date` (required, `Y-m-d`), `lines` (required, array min:2), tiap baris `account_id` (required, exists), `business_unit_id`/`currency_id`/`foreign_debit`/`foreign_credit`/`tax_rate`/`base_amount` (nullable). Jurnal balanced masuk status `JRN_PENDING_REVIEW` (auto-approve kalau `requires_journal_approval=false`), lalu di-post manual via `PUT accounting/journals/post`.

## 1.1 Deposit Booking Tamu Domestik (2026-02-02)

Tamu domestik memesan kamar untuk tanggal menginap bulan depan, bayar deposit penuh transfer ke Bank BCA. Belum check-in — **belum** ada pengakuan pendapatan, seluruhnya masuk liabilitas.

| Skenario       | Payload kunci                                                                                                           | Hasil                                                                                                                   |
| -------------- | ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Positif        | `code:"JRN-001"`, `date:"2026-02-02"`, `lines:[{AST-02,debit:5000000,bu:DEPT-ROM},{LIA-02,credit:5000000,bu:DEPT-ROM}]` | 200, jurnal balanced (Dr 5.000.000 = Cr 5.000.000), `JRN_PENDING_REVIEW`                                                |
| Positif — post | `PUT accounting/journals/post {id}`                                                                                     | 200 — Bank BCA = 350.000.000+5.000.000=**355.000.000**; Uang Muka Pemesanan Kamar = 75.000.000+5.000.000=**80.000.000** |

## 1.2 Deposit Booking Tamu Asing via Bank Mandiri Valas — USD Sungguhan (2026-02-03)

Tamu asing (dipesankan lewat Agoda) transfer deposit USD 500 langsung ke Bank Mandiri Valas. Baris `AST-03` dan `LIA-02` sama-sama diisi `currency_id:<USD>` + `foreign_debit`/`foreign_credit` — `debit`/`credit` base TIDAK dikirim manual, dihitung server via `CurrencyEngine::resolveRate()` yang mengambil rate USD yang SEDANG `is_active` di branch ini — TIDAK ada parameter tanggal, jadi tanggal jurnal (`2026-02-03`) SAMA SEKALI TIDAK MENENTUKAN rate mana yang dipakai. Rate 15.600 (di-upsert `2026-02-01` di file `00` §2) TIDAK otomatis aktif karena itu rate kedua untuk USD — harus di-`activate` eksplisit dulu (langkah persiapan di bawah) sebelum dipakai transaksi ini.

| Skenario                                      | Payload kunci                                                                                                                                                       | Hasil                                                                                                                                                                                                                                                                                                                                            |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Persiapan — aktifkan rate 15.600**          | `POST client-master/exchange-rates/activate {id:<exchange_rate_id rate 15.600>}`                                                                                    | 200 — rate 15.600 sekarang `is_active:true`, rate 15.500 nonaktif                                                                                                                                                                                                                                                                                 |
| Positif                                       | `code:"JRN-002"`, `date:"2026-02-03"`, `lines:[{AST-03,currency_id:<USD>,foreign_debit:500,bu:DEPT-ROM},{LIA-02,currency_id:<USD>,foreign_credit:500,bu:DEPT-ROM}]` | 200 — server resolve `exchange_rate:15600` (rate yang sedang aktif), `debit=credit=500×15600=7.800.000`, balanced walau field `debit`/`credit` kosong di payload                                                                                                                                                                                                          |
| Positif — post                                | `PUT .../post`                                                                                                                                                      | 200 — Bank Mandiri Valas (ekuivalen IDR) = 155.000.000+7.800.000=**162.800.000**; Uang Muka Pemesanan Kamar = 80.000.000+7.800.000=**87.800.000**                                                                                                                                                                                                |
| **Negatif — currency_id tanpa rate aktif**    | Baris dengan `currency_id` mata uang lain yang TIDAK PERNAH punya row `exchange_rates` `is_active=true` di branch ini (mis. currency baru yang belum di-upsert rate-nya sama sekali)                                                                        | Ditolak saat create: `content.no_active_exchange_rate_found_for_this_currency` (`CurrencyEngine::resolveRate()` throw `RuntimeException` kalau `ExchangeRate::rateFor()` return `null` — ditangkap controller jadi error response terstruktur) — **bukan silent-zero, bukan 500** |

## 1.3 Check-out & Pengakuan Pendapatan Kamar dengan PB1 (2026-02-05)

Tamu dari §1.1 check-out. **Baru sekarang** pendapatan kamar diakui (bukan saat deposit diterima) — deposit 5.000.000 dipecah base + PB1 10%: base = 5.000.000 ÷ 1,1 = 4.545.454,545… dibulatkan **4.545.455**, PB1 = **454.545** (4.545.455+454.545=5.000.000 persis, tidak ada sisa pembulatan).

| Skenario       | Payload kunci                                                                                                                                              | Hasil                                                                                                                                                                                                                                                                       |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Positif        | `code:"JRN-003"`, `date:"2026-02-05"`, `lines:[{LIA-02,debit:5000000,bu:DEPT-ROM},{PDT-01,credit:4545455,bu:DEPT-ROM},{LIA-03,credit:454545,bu:DEPT-ROM}]` | 200 — balanced (Dr 5.000.000 = Cr 4.545.455+454.545)                                                                                                                                                                                                                        |
| Positif — post | `PUT .../post`                                                                                                                                             | 200 — Uang Muka Pemesanan Kamar = 87.800.000−5.000.000=**82.800.000**; Pendapatan Sewa Kamar = **4.545.455**; Utang PB1 = 8.000.000+454.545=**8.454.545**                                                                                                                   |
| Negatif        | Baris pendapatan kamar tanpa pemisahan PB1 sama sekali (`lines:[{LIA-02,debit:5000000},{PDT-01,credit:5000000}]`)                                          | **LOLOS 200** — sistem TIDAK mewajibkan PB1 di level validasi (tidak ada rule backend yang mem-force pemisahan pajak daerah manual apa pun); ini murni tanggung jawab operator input jurnal yang benar, bukan gap sistem — dokumentasikan sebagai catatan proses, BUKAN bug |
