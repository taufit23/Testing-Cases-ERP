# 05. Aset Tetap (Server) & Anggaran

> **Ciri Khas Skenario**: Fokus pada pengakuan pendapatan bertahap (amortisasi retainer), tagihan recurring, dan pelacakan profitabilitas per divisi (Marketing vs Dev).
> Format pengujian mengikuti standar: **Positif** (jalur normal harus sukses) / **Negatif** (input salah harus ditolak) / **Netralisasi** (rollback).
> Endpoint aset tetap: **Assets** dan **Disposals** (BUKAN `finance/fixed-assets`). Endpoint budget: **Budgets**.

## 1. Register Aset Tetap — Server/Laptop Dev

> **Kontrak field asli Assets — `create`** (verifikasi baca kode langsung, `App\Http\Controllers\Finance\FixedAssets::create()`): `asset_code` TIDAK bisa diisi manual — server SELALU generate sendiri format `FA/{tahun}/{urutan}`, di-strip diam-diam kalau dikirim di payload. `category` HANYA menerima salah satu dari 6 nilai fix: `land|building|vehicle|equipment|furniture|intangible` — payload di bawah sudah pakai `equipment` yang valid. Nama field nilai sisa yang benar adalah `salvage_value` (bukan `residual_value`). `current_book_value` saat registrasi = **full `acquisition_cost`** (BUKAN dikurangi `salvage_value` di muka).

| Skenario               | Payload kunci                                                                                                                                                                                                                                                                                                                                                                                                                 | Hasil                                                                                                                                                                                                                                                      |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Positif                | `POST fixed-assets/assets/create {name:"Server Dedicated Hosting", category:"equipment", acquisition_date:"2026-08-01", acquisition_cost:36000000, salvage_value:0, useful_life_months:36, depreciation_method:"straight_line", asset_account_id:<akun aset — CATATAN: tidak ada akun "Aset Tetap" di COA 00, harus ditambah dulu>, depreciation_account_id:<Beban Penyusutan>, accum_dep_account_id:<Akumulasi Penyusutan>}` | 201, `asset_code` auto-generate `FA/2026/xxxx`, asset dibuat status `active`, `current_book_value:36000000` (= full `acquisition_cost`, `salvage_value` belum dipotong sama sekali saat registrasi)                                                                                                                                                                 |
| ⚠️ **Gap master data** | COA di file `00-profil-perusahaan-dan-master-data.id.md` (13 akun) TIDAK punya akun Aset Tetap, Akumulasi Penyusutan, maupun Beban Penyusutan — hanya AST-01 s/d AST-04, tidak ada aset tetap sama sekali                                                                                                                                                                                                                     | Test case ini TIDAK BISA dijalankan sampai file 00 ditambah minimal 3 akun baru (mis. `AST-05 Peralatan Kantor/Server`, `AST-06 Akumulasi Penyusutan` (contra-asset), `BBN-03 Beban Penyusutan`) — catat sebagai prasyarat, bukan asumsikan akun sudah ada |
| Negatif — tanpa nama   | `name` kosong                                                                                                                                                                                                                                                                                                                                                                                                                 | 422                                                                                                                                                                                                                                                        |

## 2. Jalankan Penyusutan

> **Assets — `create`** **TIDAK otomatis membuat jurnal penyusutan** — itu 2 action terpisah:

| Skenario                     | Detail                                                                                                                                                        | Hasil                                                                                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Positif — hitung dulu        | `POST fixed-assets/assets/calculate-depreciation {slug}`                                                                                                      | 200, preview angka penyusutan bulan berjalan TANPA posting jurnal                                                                                          |
| Positif — jalankan & posting | `POST fixed-assets/assets/run-depreciation {slug}`                                                                                                            | 200, jurnal penyusutan (Dr Beban Penyusutan / Cr Akumulasi Penyusutan) benar-benar dibuat & ter-GL, `accumulated_depreciation` pada record asset bertambah |
| Netralisasi                  | Belum ada endpoint "reverse depreciation" khusus — kalau salah, reverse jurnal penyusutan-nya lewat `accounting/journals/reverse` seperti jurnal manual biasa |

## 3. Anggaran (Budget) per Divisi (**Budgets**)

| Skenario                   | Payload kunci                                                                                                                                                                                                              | Hasil                                                                                                                                                                                                |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Positif                    | `POST accounting/budgets/create {fiscal_year_id:<FY2026>, name:"Budget Q3 Marketing", lines:[{account_id:<Beban Gaji Karyawan BBN-01>, business_unit_id:<DIV-MKT>, period_month:"2026-08-01", budgeted_amount:15000000}]}` | 200, budget status `draft`                                                                                                                                                                           |
| Negatif — nilai negatif    | `budgeted_amount: -1000000`                                                                                                                                                                                                | 422 (`min:0` di validator `lines.*.budgeted_amount`) — pesan validasi generik Laravel, BUKAN pesan custom "Invalid amount"                                                                           |
| Positif — Budget vs Actual | `POST accounting/budgets/vs-actual {slug}`                                                                                                                                                                                 | 200, `rows[]` berisi `budgeted_amount`, `actual_amount` (dihitung dari `general_ledgers` bulan+akun+`business_unit_id` yang sama, disesuaikan `normal_balance` akun), `variance`, `variance_percent` |

## Netralisasi

- Hapus asset via `DELETE fixed-assets/assets/delete` kalau belum ada penyusutan berjalan; reverse jurnal penyusutan yang sudah posted.
- Hapus budget via `DELETE accounting/budgets/delete`.
