# 05. Anggaran & Aset Tetap

> Format pengujian: **Positif** / **Negatif** / **Netralisasi**. Endpoint aset tetap: **Assets** dan **Disposals** (`fixed-assets/assets/*`, `fixed-assets/disposals/*` — BUKAN `finance/fixed-assets`). Endpoint budget: **Budgets** (`accounting/budgets/*`).
>
> Karena 1 branch, tidak ada lagi duplikasi aset/budget per branch. Pembeda antar divisi: untuk **Budget**, `budgets` punya kolom `business_unit_id` langsung di baris (`budgets.business_unit_id`, ditambahkan lewat migrasi `add_business_unit_id_to_budgets_table`) — bisa diisi eksplisit per baris. Untuk **Fixed Assets**, TIDAK ada kolom `business_unit_id` langsung di tabel `assets` — tagging divisi untuk aset dilakukan secara TIDAK LANGSUNG lewat `asset_account_id` yang mengarah ke akun COA yang sudah di-tag `default_business_units_id` (mis. AST-08 → `BU-CONSULT`, AST-09 → `BU-RETAIL`, lihat file 00 §4). Jangan mengarang kolom `business_unit_id` di payload `Assets — create`, itu tidak ada di skema.

## 1. Register Aset Tetap — Laptop/Server Konsultan (tag BU-CONSULT via akun)

> **Kontrak field asli `Assets — create`** (`App\Http\Controllers\Finance\FixedAssets::create()`): `asset_code` SELALU digenerate server format `FA/{tahun}/{urutan}` (di-strip diam-diam kalau dikirim manual). `category` HANYA menerima `land|building|vehicle|equipment|furniture|intangible`. Nama field nilai sisa yang benar `salvage_value` (bukan `residual_value`). `current_book_value` saat registrasi = **full `acquisition_cost`**, `salvage_value` belum dipotong di muka.

| Skenario                          | Payload kunci                                                                                                                                                                                                                                                                                                                                                                                                                             | Hasil                                                                                                                                                                                   |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Positif — 5 unit laptop konsultan | `POST fixed-assets/assets/create {name:"Laptop Konsultan Lenovo ThinkPad (5 unit)", category:"equipment", acquisition_date:"2026-08-01", acquisition_cost:75000000, salvage_value:5000000, useful_life_months:36, depreciation_method:"straight_line", asset_account_id:<AST-08 Peralatan IT Konsultan, BU Default = BU-CONSULT>, depreciation_account_id:<BBN-03 Beban Penyusutan>, accum_dep_account_id:<AST-10 Akumulasi Penyusutan>}` | 201, `asset_code` auto-generate `FA/2026/xxxx`, status `active`, `current_book_value:75000000` — tag divisi terbaca lewat `asset_account_id` (AST-08), BUKAN field langsung di `assets` |
| Positif — server internal         | `create {name:"Server Rack Internal untuk Hosting Proyek Klien", category:"equipment", acquisition_cost:40000000, salvage_value:0, useful_life_months:48, asset_account_id:<AST-08>, ...}`                                                                                                                                                                                                                                                | 201, aset kedua terdaftar                                                                                                                                                               |
| Negatif — tanpa nama              | `name` kosong                                                                                                                                                                                                                                                                                                                                                                                                                             | 422                                                                                                                                                                                     |
| Negatif — category invalid        | `category:"laptop"` (bukan salah satu dari 6 nilai fix)                                                                                                                                                                                                                                                                                                                                                                                   | 422                                                                                                                                                                                     |

## 3. Jalankan Penyusutan (kedua aset, di branch yang sama)

> **`Assets — create` TIDAK otomatis membuat jurnal penyusutan** — 2 action terpisah.

| Skenario                                        | Detail                                                                                                                                | Hasil                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Positif — hitung dulu (Laptop Konsultan)        | `POST fixed-assets/assets/calculate-depreciation {slug:<Laptop Konsultan>}`                                                           | 200, preview angka penyusutan bulan berjalan TANPA posting jurnal — `(75.000.000-5.000.000)/36 = 1.944.444`/bulan                                                                                                                                                                          |
| Positif — jalankan & posting (Laptop Konsultan) | `POST fixed-assets/assets/run-depreciation {slug}`                                                                                    | 200, jurnal penyusutan (Dr BBN-03 / Cr AST-10) ter-GL. Baris jurnal penyusutan otomatis ini **TIDAK di-tag `business_unit_id`** kecuali di-set manual — verifikasi apakah `run-depreciation` menurunkan tag BU dari `asset_account_id`-nya atau kosong (catat sebagai temuan kalau kosong) |
| Positif — jalankan & posting (Rak Display)      | Sama, aset "Rak Display" — `(18.000.000-1.000.000)/60 = 283.333`/bulan                                                                | 200, jurnal penyusutan ter-GL, di COA yang sama, hanya beda akun sumber (AST-09 vs AST-08)                                                                                                                                                                                                 |
| Netralisasi                                     | Belum ada endpoint "reverse depreciation" — reverse jurnal penyusutan lewat `accounting/journals/reverse` seperti jurnal manual biasa |

## 4. Anggaran (Budget) per Business Unit (**Budgets**)

| Skenario                   | Payload kunci                                                                                                                                                                                                                      | Hasil                                                                                                                                                                             |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Positif                    | `POST accounting/budgets/create {fiscal_year_id:<FY2026>, name:"Budget Q3 Divisi Managed Services", lines:[{account_id:<BBN-01 Beban Gaji>, business_unit_id:<BU-MANAGED>, period_month:"2026-08-01", budgeted_amount:20000000}]}` | 200, budget status `draft`                                                                                                                                                        |
| Negatif — nilai negatif    | `budgeted_amount: -1000000`                                                                                                                                                                                                        | 422 (`min:0` di validator) — pesan validasi generik Laravel                                                                                                                       |
| Positif                    | `create` budget kedua untuk `BU-RETAIL` — `lines:[{account_id:<BBN-02 Beban Sewa>, business_unit_id:<BU-RETAIL>, period_month:"2026-08-01", budgeted_amount:8000000}]}`                                                            | 200, budget draft, dalam fiscal year yang sama (1 branch)                                                                                                                         |
| Positif — Budget vs Actual | `POST accounting/budgets/vs-actual {slug}`                                                                                                                                                                                         | 200, `rows[]` berisi `budgeted_amount`, `actual_amount` (dari `general_ledgers` bulan+akun+`business_unit_id` sama, disesuaikan `normal_balance`), `variance`, `variance_percent` |

## Netralisasi

- Hapus asset via `DELETE fixed-assets/assets/delete` kalau belum ada penyusutan berjalan; reverse jurnal penyusutan yang sudah posted.
- Hapus budget via `DELETE accounting/budgets/delete`.
