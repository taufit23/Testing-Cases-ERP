## B. Hubungan antar modul (sumber: bab Hubungan Antar Modul)

Setiap baris memeriksa satu hubungan: lakukan aksi di modul asal, lalu buka modul tujuan.

| Skenario | Langkah dan data uji | Hasil yang diharapkan |
| --- | --- | --- |
| Positif — Delivery ke stok | Setujui Delivery Sales Order | Stok gudang berkurang sebesar qty (Inventory, Stock Card) |
| Positif — Sales Return ke stok | Setujui Sales Return | Stok bertambah |
| Positif — Goods Receipt ke stok | Setujui Goods Receipt dari PO | Stok bertambah; PO berubah status otomatis |
| Positif — Purchase Return ke stok | Selesaikan Purchase Return (Complete) | Stok berkurang hanya saat Complete, bukan saat disetujui |
| Positif — Dokumen ke jurnal | Setujui Sales Invoice dengan pemetaan akun lengkap | Jurnal terbentuk di Accounting dengan akun sesuai pemetaan |
| Positif — HPP | Delivery barang berbiaya lebih dari nol saat fungsi persediaan dan HPP terpetakan | Jurnal HPP debit HPP, kredit persediaan; bila salah satu belum terpetakan, jurnal HPP tidak terbentuk |
| Positif — PO dari Sales Order | Buat PO dengan Sales Order asal, baris tanpa memilih item Sales Order | Baris PO tertaut ke item Sales Order ber-SKU sama |
| Negatif — PO ke Sales Order cabang lain | Pilih Sales Order milik cabang lain | Ditolak: tidak ditemukan di cabang |
| Negatif — Item dari Sales Order berbeda | Tautkan baris PO ke item Sales Order yang bukan dari Sales Order header | Ditolak dengan pesan baris tertaut ke Sales Order berbeda |
| Positif — Rebill biaya | Faktur biaya logistik dengan baris ditandai tagih ulang | Tab Rebill menampilkan statusnya dan tertaut ke Sales Order |
| Positif — Rental ke kunjungan | Rental Order dari kunjungan kanvasing | Rental Order menampilkan kunjungan asal |
| Positif — Pencatatan Bahan restoran | Simpan Pencatatan Bahan | Terbentuk penyesuaian stok di Inventory |
| Positif — POS | Selesaikan transaksi POS, tutup sesi | Stok bergerak dan jurnal terbentuk; tutup sesi dan refund juga terjurnal |
| Positif — Produksi | Keluarkan bahan dan selesaikan Production Order | Stok bahan berkurang, stok barang jadi bertambah, jurnal produksi terbentuk |
| Positif — Mining | Verifikasi Production Log dan Delivered Hauling lalu Generate royalti | Stok stockpile bergerak; jurnal terbentuk dari royalti |
| Positif — Payout | Siapkan dan kirim payout gaji, komisi, biaya, dan tagihan pembayaran | Transfer bank tercatat dengan status payout; sumbernya menandai terbayar |
| Positif — Pelanggaran ke GA | Pelanggaran karyawan dengan kategori kesalahan GA | Tertaut ke Penyelesaian Ganti Rugi di General Affairs |
| Positif — Unit GA ke aset | Unit GA terhubung aset tetap | Aset tetap tampil di unit |
| Positif — Tugas Proyek ke dokumen | Tautkan tugas ke Sales Order, PO, Production Order, dan Rental Order | Tugas menampilkan nomor dan tautan dokumen; dokumen cabang lain ditolak |
| Negatif — Hapus dokumen berdampak | Hapus dokumen yang sudah menggerakkan stok atau jurnal | Ditolak atau harus dibatalkan lewat dokumen pembalik |
| Aturan — Tanpa persetujuan | Matikan persetujuan modul lalu kirim dokumen | Dokumen langsung Approved dan dampak stok atau jurnal terjadi saat itu |

## Titik uji kunci modul ini

- Tiap diagram tampil sebagai gambar di tema terang dan gelap.
- Setiap dampak lintas modul terjadi tepat pada status yang disebut bab (Approved atau Complete).
