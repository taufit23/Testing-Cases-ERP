## B. Catatan string janggal (isi saat menemukan)

Satu baris per temuan. Format ini sengaja dibuat supaya bisa langsung dipakai untuk memperbaiki terjemahan secara massal.

> **Baris 1 sampai 16 sudah terisi dari hasil membaca tabel terjemahan aplikasi** (belum dilihat langsung di layar). Cocokkan dengan layar; kalau ternyata sudah benar di layar, coret barisnya. Tambahkan temuanmu di baris kosong di bawahnya.

| # | Halaman atau menu | String yang tampil sekarang | Yang seharusnya | Jenis | Catatan |
| ---: | --- | --- | --- | --- | --- |
| 1 | Core, menu Providers | Penyuplai | Klien (perusahaan pelanggan) | Salah arti | Provider di aplikasi ini = perusahaan klien, bukan pemasok. Pemasok sudah punya kata sendiri (Supplier) |
| 2 | Laporan Accounts Payable Aging | Umur Piutang Usaha | Umur Utang Usaha | Salah arti | Payable = utang. Piutang itu Receivable |
| 3 | Tombol Add Usage (Kerjasama) | Kemitraan Tambahkan Penggunaan | Tambah Pemakaian | Salah ketik / awalan nyasar | Kata Kemitraan nyasar di depan. Bandingkan dengan label Usage lain: Pemakaian |
| 4 | Tombol Generate Settlement (Kerjasama) | Kemitraan Menghasilkan Penyelesaian | Buat Rekap Penyelesaian | Salah ketik / awalan nyasar | Awalan Kemitraan nyasar; Generate di tempat lain = Buat |
| 5 | Menu Billing Prices | Harga PengecekanPenagihan | Harga Penagihan | Mentah / terduplikasi | Dua terjemahan menempel jadi satu kata |
| 6 | Tombol Mark as Paid | Konfirmasikan Tandai Bayar | Tandai Sudah Dibayar | Mentah / terduplikasi | Dua frasa menempel |
| 7 | Kolom Is Retained Earnings Account | Akun Laba Merosot | Akun Laba Ditahan | Salah arti | Retained earnings = laba ditahan |
| 8 | Tombol Check In / Check Out | Masuk / Lakukan Pengecekan | Cek-In / Cek-Out | Tidak konsisten | Masuk bentrok dengan Login yang juga Masuk; dan status Checked In = Sudah Cek-In |
| 9 | Tombol Apply | Terapikan | Terapkan | Salah ketik |  |
| 10 | Tombol Create Production Order | Buat Produksi | Buat Perintah Produksi | Terlalu singkat | Kata Order hilang; di menu lain Order = Pesanan |
| 11 | Laporan Inventory Reconciliation | Rekonsiliasi Inventaris | Rekonsiliasi Persediaan | Tidak konsisten | Inventory di menu utama = Persediaan |
| 12 | Menu Settlements | Penyelarasan Kerjasama | Penyelesaian Kerjasama | Salah arti / tidak konsisten | Settlement di tempat lain = Penyelesaian |
| 13 | Tombol Record Customer Declined | Catatan Pelanggan Ditolak | Catat Pelanggan Menolak | Tidak konsisten | Tombol lain memakai kata kerja (Catat Retur, Catat Sedang Negosiasi) |
| 14 | Menu Partner Overview, Subscription Plans, Show Product Pictures | Ringkasan mitra / Paket langganan / Tampilkan gambar produk | Ringkasan Mitra / Paket Langganan / Tampilkan Gambar Produk | Tidak konsisten | Huruf besar kecil berbeda dari label lain (Title Case) |
| 15 | Dasbor POS, Todays Sales | (sumber) Todays Sales | Today's Sales | Salah ketik (sumber Inggris) | Apostrof hilang di kunci aslinya |
| 16 | Tombol Confirm All | Konfirmasikan Semua | Konfirmasi Semua | Terlalu panjang | Bandingkan Needs Confirmation = Perlu Konfirmasi |
| 17 | HRM → Departemen, tombol tambah | Tambah Bagian / Tambah Departemen (dua versi) | Tambah Departemen | Tidak konsisten | Menu bernama Departemen tetapi tombolnya Bagian di sebagian bahasa |
| 18 | HRM → Jabatan, tombol tambah | Tambah Posisi | Tambah Jabatan | Tidak konsisten | Menunya Jabatan, tombolnya Posisi |
| 19 | | | | | |
| 20 | | | | | |

**Jenis yang disarankan:** Salah arti, Masih berbahasa Inggris, Tidak konsisten (dua kata untuk hal yang sama), Terlalu panjang atau terpotong, Salah ketik, Mentah (tampil seperti kode, mis. `content.xxx`).
