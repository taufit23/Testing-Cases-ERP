# Testing Cases

Folder ini menampung **test case manual berbasis skenario bisnis** (bukan otomatis/PHPUnit) — beda dengan `docs/testing-flow-core-to-purchasing.id.md` yang generik lintas-modul dan berorientasi endpoint API. Test case di sini disusun per **1 sub-folder per modul**, masing-masing dibangun di atas **1 skenario perusahaan konkret** (nama, jenis usaha, struktur akun, data master) supaya test case terasa nyata dan saling nyambung — bukan potongan skenario lepas-lepas.

Format tiap file konsisten dengan `docs/testing-flow-core-to-purchasing.id.md`: tabel **Positif** (jalur normal harus sukses) / **Negatif** (input salah harus ditolak dengan jelas, bukan crash/silent-fail) / **Netralisasi** (cara mengembalikan state ke semula setelah testing).
