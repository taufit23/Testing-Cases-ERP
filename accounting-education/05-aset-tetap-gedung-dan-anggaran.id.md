# 05. Aset Tetap Gedung & Anggaran

> Prasyarat: [`01-jurnal-spp-dan-beasiswa.id.md`](./01-jurnal-spp-dan-beasiswa.id.md) §1.13-1.14 selesai — `FA/2026/0001` (Gedung Sekolah) dan `FA/2026/0002` (Peralatan Laboratorium IPA) sudah terdaftar dan jurnal akuisisinya posted. Endpoint dikonfirmasi dari `routes/fixed_assets.php`: **Assets** (`calculate-depreciation`, `run-depreciation`) dan **Disposals**; `routes/accounting.php`: **Budgets**.

## 5.1 Lengkapi Konfigurasi Akun Penyusutan per Aset

`runDepreciation()` HANYA memposting jurnal GL kalau `depreciation_account_id` DAN `accum_dep_account_id` sudah terisi di record aset (dikonfirmasi dari `FixedAssets::runDepreciation()` — kalau salah satu kosong, `AssetDepreciation` tetap tercatat tapi `is_posted:false`, GL TIDAK terbentuk, silent no-op per-aset).

| Skenario                                    | Payload                                                                                                                                            | Hasil                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Positif — Gedung Sekolah                    | `PUT fixed-assets/assets/update {slug:"fa-2026-0001", depreciation_account_id:<BBN-05>, accum_dep_account_id:<AST-07>, asset_account_id:<AST-06>}` | 200                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Positif — Peralatan Laboratorium            | `PUT fixed-assets/assets/update {slug:"fa-2026-0002", depreciation_account_id:<BBN-06>, accum_dep_account_id:<AST-09>, asset_account_id:<AST-08>}` | 200                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Negatif — regresi jika lupa langkah ini** | Jalankan `run-depreciation` TANPA mengisi kedua akun ini dulu                                                                                      | `AssetDepreciation` record tetap kebuat (`is_posted:false`), tapi TIDAK ada jurnal GL — kalau tim lupa jalankan §5.1 sebelum §5.3, laporan keuangan file `04` TIDAK akan menunjukkan beban penyusutan sama sekali walau `fixed-assets/assets/list` sudah menunjukkan `current_book_value` berkurang di UI kalkulasi terpisah — 🆕 gap koordinasi antara "kalkulasi ditampilkan" vs "GL benar-benar terupdate", sama seperti temuan serupa di suite F&B/manufaktur |

## 5.2 Simulasi Skedul Penyusutan (Read-Only, `calculate-depreciation`)

| Skenario                                             | Payload                                                                                          | Hasil                                                                                                                                                                                                                                                                                                 |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Positif — Gedung Sekolah (straight-line)             | `POST fixed-assets/assets/calculate-depreciation {slug:"fa-2026-0001", as_of_date:"2026-05-31"}` | `schedule` 2 baris: April `depreciation_amount:500000, book_value_after:119500000`; Mei `depreciation_amount:500000, book_value_after:119000000` — (120.000.000−0)/240 = 500.000/bulan tetap tiap bulan (ciri straight-line)                                                                          |
| Positif — Peralatan Laboratorium (declining-balance) | `POST fixed-assets/assets/calculate-depreciation {slug:"fa-2026-0002", as_of_date:"2026-05-31"}` | `schedule` 2 baris: April `depreciation_amount:600000, book_value_after:17400000` (18.000.000×(2/60)=600.000); Mei `depreciation_amount:580000, book_value_after:16820000` (17.400.000×(2/60)=580.000) — menurun tiap bulan (ciri declining-balance), TIDAK PERNAH di bawah `salvage_value` 1.800.000 |
| Negatif                                              | `slug` aset milik branch lain                                                                    | 422 `not_found_in_branch`                                                                                                                                                                                                                                                                             |

## 5.3 Jalankan Penyusutan Riil (`run-depreciation`) — April 2026

| Skenario                                            | Payload                                                                          | Hasil                                                                                                                                                                                                                                                                                                                                               |
| --------------------------------------------------- | -------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Positif                                             | `POST fixed-assets/assets/run-depreciation {period_date:"2026-04-01"}`           | `{created:2, skipped:0}` — memproses SEMUA aset `status:active` di branch, bukan per-aset; jurnal `DEP-20260401-0001` (Gedung, Dr BBN-05 500.000 / Cr AST-07 500.000) dan `DEP-20260401-0002` (Lab, Dr BBN-06 600.000 / Cr AST-09 600.000) otomatis ter-post (`posted_at` langsung terisi, TIDAK melalui status draft/review seperti jurnal manual) |
| **Negatif — jalankan lagi untuk periode yang sama** | `POST fixed-assets/assets/run-depreciation {period_date:"2026-04-01"}` (diulang) | `{created:0, skipped:2}` — `AssetDepreciation` sudah ada untuk `period_date` ini, di-skip, TIDAK dobel posting (guard `exists()` per `fixed_asset_id` + `period_date`)                                                                                                                                                                              |
| Positif — Mei 2026                                  | `POST fixed-assets/assets/run-depreciation {period_date:"2026-05-01"}`           | `{created:2, skipped:0}` — Gedung: `AST-06 book_value 119.500.000→119.000.000`; Lab: `AST-08 book_value 17.400.000→16.820.000`                                                                                                                                                                                                                      |

Setelah April+Mei: Akumulasi Penyusutan Gedung (AST-07) = 500.000×2 = **1.000.000**; Akumulasi Penyusutan Lab (AST-09) = 600.000+580.000 = **1.180.000**. Beban Penyusutan Gedung (BBN-05) = **1.000.000**; Beban Penyusutan Lab (BBN-06) = **1.180.000**.

| Skenario                                                  | Detail                                                                   | Hasil                                                                                                                                                      |
| --------------------------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Positif — kontra-aset tampil negatif di Trial Balance** | `POST accounting/general-ledger/trial-balance {as_of_date:"2026-05-31"}` | AST-07 dan AST-09 muncul dengan saldo **negatif** (mengurangi total Aset Tetap kotor AST-06+AST-08), konsisten dengan flag yang dijelaskan di file `00` §3 |

## 5.4 Disposal — Peralatan Laboratorium Rusak Sebelum Umur Ekonomis Habis

Simulasi 1 unit peralatan lab (dari `FA/2026/0002`, WALAU sebenarnya didaftarkan sebagai 1 baris aset gabungan — pola yang sama seperti file `01` suite manufaktur, disposal dianggap "seluruh baris aset" karena sistem tidak melacak unit individual per baris) rusak karena kecelakaan lab dan tidak bisa dipakai lagi.

| Skenario                                             | Payload                                                                                                                                                                                      | Hasil                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Positif                                              | `POST fixed-assets/disposals/create {fixed_asset_id:<id aset FA/2026/0002>, disposal_date:"2026-05-31", disposal_type:"scrapped", disposal_proceeds:0, notes:"Rusak akibat kecelakaan lab"}` | 201 — `book_value_at_disposal:16820000` (nilai buku Mei), `gain_loss: 0 - 16820000 = -16820000` (kerugian penuh, tidak ada nilai sisa dari scrap), asset `status` berubah jadi `disposed`                                                                                                                                                                                                                                                 |
| **Negatif**                                          | Coba `disposals/create` lagi untuk aset yang SAMA (sudah `status:disposed`, bukan `active`)                                                                                                  | 422 `asset_not_active`                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Catatan proses 2-langkah (sama seperti akuisisi)** | `AssetDisposals::create()` HANYA mencatat data disposal — TIDAK otomatis posting jurnal pelepasan aset (Dr Akumulasi Penyusutan + Dr Rugi Pelepasan Aset / Cr Aset Tetap)                    | Jurnal pelepasan HARUS dibuat manual terpisah: `lines:[{AST-09,debit:1180000},{BBN-06,debit:16820000},{AST-08,credit:18000000}]` (Dr Akumulasi Penyusutan Lab 1.180.000 + Dr Rugi Pelepasan Aset — dipakai akun BBN-06 sementara TIDAK ADA akun "Rugi Pelepasan Aset" terpisah di baseline COA suite ini, catat sebagai keterbatasan; idealnya tambah akun baru — / Cr Peralatan Laboratorium 18.000.000, balanced 18.000.000=18.000.000) |
| Netralisasi                                          | JANGAN reverse — disposal ini sengaja permanen untuk mendemonstrasikan alur akhir siklus hidup aset, konsisten dengan suite lain                                                             |
