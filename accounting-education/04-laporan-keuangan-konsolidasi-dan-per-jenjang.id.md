# 04. Laporan Keuangan Konsolidasi & per Jenjang

> Prasyarat: [`01-jurnal-spp-dan-beasiswa.id.md`](./01-jurnal-spp-dan-beasiswa.id.md) selesai, [`02-general-ledger-trial-balance-per-jenjang.id.md`](./02-general-ledger-trial-balance-per-jenjang.id.md) sudah dikonfirmasi balanced. Endpoint dikonfirmasi dari `routes/reports.php`, controller `App\Http\Controllers\Reports\ReportController`: `income-statement` (param `start_date`/`end_date`), `balance-sheet` (param `as_of_date`), `cash-flow-statement` (param `start_date`/`end_date`).
>
> **Keterbatasan penting dikonfirmasi dari kode**: `incomeStatement()`/`balanceSheet()`/`cashFlowStatement()` TIDAK menerima parameter `business_unit_id`/dimensi apapun — hanya `general-ledger/summary-by-account` (dipakai file `02`) yang mendukung filter dimensi. Jadi breakdown per jenjang di file ini didapat dengan MENGGABUNGKAN hasil §2.2/§2.3 (GL per jenjang), BUKAN dari endpoint `reports/*` langsung — catat ini sebagai keterbatasan skenario, bukan bug (sama seperti temuan di `../accounting-fnb-kafe/04-laporan-keuangan-konsolidasi-dan-per-outlet.id.md` §4.3).

## 4.4 Arus Kas / Cash Flow Statement (**Cash Flow Statement**)

Metode langsung (direct method) — mengklasifikasi tiap baris GL yang menyentuh akun `is_cash_account:true` (AST-01, AST-02, AST-03) berdasarkan `cash_flow_section` dari akun kontra di baris lawannya.

| Skenario                                                 | Payload                                                                                                 | Hasil                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Positif                                                  | `POST reports/cash-flow-statement {start_date:"2026-03-01", end_date:"2026-03-31"}`                     | Section **Operating**: penerimaan SPP (§1.3, kontra Piutang = operating), pembayaran gaji (§1.5, kontra Beban = operating), pembayaran PPh 21 (§1.6, kontra Liability jangka pendek = operating), pembayaran listrik (§1.9, kontra Beban = operating), selisih kas (§1.11, kontra Beban = operating); Section **Investing**: akuisisi Gedung Sekolah (§1.13, −120.000.000, kontra Aset Tetap = investing) dan Peralatan Laboratorium (§1.14, −18.000.000); Section **Financing**: suntikan dana yayasan (§1.12, +60.000.000, kontra Ekuitas = financing) |
| **Positif — mutasi antar-akun kas TIDAK dihitung dobel** | Cek baris setoran kas bendahara ke bank (§1.10: Dr AST-03 / Cr AST-01, keduanya `is_cash_account:true`) | Mutasi kas-ke-kas ini TIDAK boleh muncul sebagai in-flow maupun out-flow di Cash Flow Statement (kas berpindah antar akun kas sendiri, bukan aktivitas operasi/investasi/pendanaan) — kalau muncul, itu double-counting, catat sebagai gap                                                                                                                                                                                                                                                                                                               |
| Negatif                                                  | Rentang tanggal di luar aktivitas apapun (mis. `start_date/end_date` bulan Januari)                     | Semua section 0, `net_cash_flow: 0` — bukan error                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
